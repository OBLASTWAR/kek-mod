# Moved

The Civ V Mod Installer now lives in
**[OBLASTWAR/civ5-mod-installer](https://github.com/OBLASTWAR/civ5-mod-installer)**.
Download the latest
[`CivVModInstaller.exe`](https://github.com/OBLASTWAR/civ5-mod-installer/releases/latest/download/CivVModInstaller.exe)
from there.

The files left in this folder are frozen copies of installer 2.4, the first
release from the new repo. Installers up to 2.3 update themselves from these
exact paths, so don't delete or rename them:

- `KekModInstaller.exe`, `CivVModInstaller.exe`: the 2.4 Windows build under
  both names that old copies request
- `installer_version.txt`: `2.4`, which makes old copies offer the update
- `linux/civ5-mod`: the 2.4 Linux installer
- `ticker.txt`: the ticker text old copies show. Edit the new repo's copy for
  2.4 and later.

Once they're on 2.4, installers only talk to the new repo.
